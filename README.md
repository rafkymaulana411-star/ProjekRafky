# ProjekRafky

Kumpulan proyek latihan Android Studio oleh **Rafky Maulana**.

## Daftar Proyek

1. **AplikasiPertama** - Proyek pengenalan dasar pembuatan aplikasi Android.
2. **IntentActivity** - Implementasi perpindahan antar Activity menggunakan Intent.
3. **MenghitungNilaiMahasiswa** - Aplikasi perhitungan nilai mahasiswa berbasis Android.
4. **MengirimDataAntarActivity** - Implementasi transfer data antar Activity menggunakan Intent & Bundle.

---
*Dibuat menggunakan Android Studio.*
